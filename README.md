🚀 Bringing Smart Meter Data to Life with Modern Web Tech⚡

I recently wanted a better way to visualize my home electricity consumption beyond the raw, clunky CSV files provided by my utility company Sibelga. So, I built a custom **Smart Electricity Dashboard** to track, analyze, and visualize my off-peak vs. peak usage in real time!

I focused heavily on UI/UX, aiming for a premium "glassmorphism" aesthetic with smooth interactions and deep data insights (including total usage, average loads, and estimated cost calculations). 

🛠️ Built with an awesome tech stack:
🔹 React & Vite – For a lightning-fast development experience and optimized builds
🔹 Tailwind CSS (v4) – For the sleek, responsive, utility-first styling and frosted glass effects
🔹 Framer Motion – To handle all the buttery-smooth staggered entrance animations and hover states
🔹 Recharts – For rendering the dynamic, responsive area charts with custom SVGs, gradients, and glowing drop-shadows
🔹 Lucide React – For crisp, lightweight iconography 

It was a fantastic exercise in handling complex data parsing (dealing with granular 15-minute interval datasets) and translating it into an intuitive, beautiful dashboard.
